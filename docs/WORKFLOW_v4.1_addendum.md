# v4.1 增量：将规范转成可复用代码

**v4.0 原文保留不变**；新增模块为 `core/`，配置为 `config/`，每次任务专属输入为 `deck.json`。

## 固定代码 vs 每次任务变动

- 固定不变：绘制文字框、原生形状、连接线、表格、图表、插入图标、保持图片比例、PPTX 输出、机器 QA、预览。
- 每次需生成：每页参考图拆解、具体文字、对象类型、坐标、选定图标 ID、图表真实数据、连接方向和遮挡关系。
- 有条件执行：复杂设备提取、可靠文字识别、参考图与 PPT 渲染稿的视觉比对、复杂页面人工精修。

## 最低复杂度原则

先以一份 JSON + 单个通用 Builder 解决多数重复代码，不引入多智能体、训练模型或自定义私有接口。只有对大量不同来源图片做完整无人值守还原存在稳定需求，并取得标注数据/评价协议后，才考虑自动视觉识别与几何估计。

## 必要的二级测试

1. 运行样例，确认 `.pptx` 正常打开并包含可编辑文字、卡片、箭头。
2. 在 PowerPoint 或 WPS 中检查中文字体换行与连接箭头。
3. 向样例 JSON 增加表格/真实图表，确认可直接编辑。
4. 用复杂截图构造 JSON，记录未能原生实现的对象及原因；作为后续优化的真实失败样本。

## 后续扩展（不宣称现已完成）

按优先级：文本实际溢出可靠检测 → SVG 原生矢量嵌入 → 布局模板库 → 原PPT读取和美化 → 对比参考图的结构差异 → 高复杂度页面分层素材提取 → 自动修复。
