# v4.4 图形语义识别与布局候选｜实现与验收

## 实现内容

| 子模块 | 方法 | 输出 | 约束 |
|---|---|---|---|
| 图形轮廓 | OpenCV Canny + 轮廓近似/角度/圆度 | 矩形、椭圆、菱形、三角形候选 | 仅几何类别，不代表业务语义 |
| 箭头候选 | Hough 线段与三角形/V 形箭头头部配对，并排除 OCR 文本框和卡片边框上的线段 | 起终点、方向、置信度 | 复杂折线、弧线、虚线和交叉线仍需复核 |
| 表格网格 | 横/纵形态学线提取、投影分组 | 行列数、网格坐标 | 无网格线表格可能漏检 |
| OCR 落格 | 文本框中心点映射到单元格 | 初始 rows 数组 | OCR 漏字/错字会传递到单元格 |
| 图标候选 | 小型紧凑视觉连通区域 + 邻近 OCR 标签 | 候选区域、500 SVG 语义候选（基于邻近 OCR 标签的排序分，不是概率） | 不是像素级图标分类，必须核对 |
| 布局假设 | 同尺寸矩形的中心线对齐/间距分析 | 重复卡片行/列候选 | 只提供几何假设，不自动重排 |
| 审核叠加图 | 多色绘制结构候选 | `overlay_*.png` | 颜色仅代表候选类别，不代表置信度已校准 |

## 运行

```powershell
python -m pip install -r requirements.txt
python -m pip install -r requirements-image-analysis.txt
python run_workflow.py analyze-image --input "D:\PPT图片\批次" --output-dir outputs\v44_batch --build-draft
```

`--engine none` 可跳过 OCR，但仍执行 OpenCV 几何结构分析；没有 OCR 文本框时会跳过邻近标签驱动的图标建议。没有 OpenCV 时会输出警告，不影响原有 PPT 构建模块。

## 验收

- 9 项新增合成测试覆盖几何类型、箭头方向与误报约束、表格 OCR 落格、图标语义候选、重复卡片、draft schema、PPTX 原生对象构建和叠加图输出。
- 完整回归：33 项 unittest 全部通过；基础 `smoke_test.py` 通过。
- 这些测试是合成几何/工程测试，不是对真实中文 PPT 截图的准确率基准；没有宣称像素级图标识别或一键高保真。

## 复核规则

1. 图形候选先核对边界、类型、填充和层级。
2. 箭头必须核对起点、终点、方向以及是否连接到正确节点。
3. 表格必须核对行列数、合并单元格、空单元格和文本内容。
4. 图标建议必须看 SVG 实际图形，不能只因关键词相似就自动写入正式 JSON。
5. 重复布局只作分组提示，不自动把原图重排成新版式。
6. 所有分析草稿保持 `REVIEW_REQUIRED`，人工复核后再正式 build。
