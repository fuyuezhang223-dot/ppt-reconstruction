# Security Policy

## Supported versions

Security reports are accepted for the latest published repository version.

## Reporting a vulnerability

Please do not publish secrets, private slide decks, or exploit details in a public issue. Contact the repository maintainer privately through the GitHub profile or repository security contact after the repository is created.

## Data handling

The current project is a local Python CLI and Agent Skill. It does not upload slide images to a hosted service. If a user configures an external OCR or vision API in a future integration, that integration must document its data handling separately.
