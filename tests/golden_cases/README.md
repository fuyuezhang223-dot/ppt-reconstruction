# 真实参考页面回归集（待补充）

这里应放置经用户许可使用的 8—12 张**真实截图/原始PPT参考页**，分别覆盖：单页学术流程、多分支/多连线、数据表、设备图文、三卡片、时间轴、信息密集、字体异常、图标繁多、图片裁剪等。

每个案例推荐提供 `source.png`、`reference_bboxes.json`（记录人工确认与不确定性）、`page_spec.json`、`expected_qa.json` 和可重建的 `generated.pptx`。用定量指标跟踪：内容一致率、页面几何偏差、原生对象占比、人工修改次数、真实P0/P1漏报率。

当前本项目中的 `examples/synthetic_qa/` **仅用于合成自测**。不可作为上述真实样本集的代替品，也不能据此对高保真率做统计结论。
